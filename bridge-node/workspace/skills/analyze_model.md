## analyze_model — 模型分析

### 描述

解析 CLI 工具输出的模型分析 JSON，提取关键特征，识别影响切片策略的因素。

### 输入

CLI 工具 `voxelflow --analyze-only` 输出的 JSON 数据。

### 处理流程

```
1. 读取 JSON 数据
2. 提取关键指标:
   ├── Bounding Box → 判断是否适配打印平台
   ├── 面片数 → 评估模型复杂度
   ├── 体积 → 估算耗材用量
   ├── 悬垂分析 → 判断是否需要支撑及支撑类型
   ├── 薄壁分析 → 判断是否需要调整层高/线宽
   └── 桥接分析 → 判断是否需要桥接策略
3. 生成分析报告:
   ├── 模型基本信息（尺寸、面片数、体积）
   ├── 风险评估（悬垂、薄壁、桥接）
   ├── 推荐打印方向
   └── 关键切片参数建议
```

### 输出

结构化分析报告，包含：

```markdown
## 模型分析报告

### 基本信息
- 尺寸: W×D×H mm
- 面片数: N
- 体积: N mm³
- 估算质量: N g（按 PLA 1.24 g/cm³）

### 风险评估
| 风险项 | 程度 | 说明 |
|--------|------|------|
| 悬垂 | 高/中/低 | 最大角度 N°, 悬垂面积比 N% |
| 薄壁 | 高/中/低 | 最小壁厚 N mm, 薄壁面积比 N% |
| 桥接 | 高/中/低 | 最大桥接长度 N mm, 桥接面积比 N% |

### 切片建议
- 打印方向: [推荐旋转角度]
- 层高: N mm
- 支撑: 类型 + 理由
- 特殊策略: [如有]
```

### 判断规则

| 指标 | 阈值 | 判断 |
|------|------|------|
| 悬垂角度 | > 45° | 必须支撑 |
| 悬垂角度 | 30°-45° | 建议支撑 |
| 悬垂面积比 | > 30% | 高风险，Tree 支撑 |
| 薄壁面积比 | > 20% | 需降层高 |
| 最小壁厚 | < 0.8mm | 薄壁警告 |
| 桥接长度 | > 20mm | 高风险桥接 |
| 桥接面积比 | > 10% | 需桥接策略 |
| 模型高度 | > 200mm | 长时间打印警告 |
