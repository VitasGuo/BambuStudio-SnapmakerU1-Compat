## review_gcode — G-code 审查

### 描述

对生成的 G-code 进行 7 维度质量检查，识别潜在问题。

### 检查维度

#### 4.1 尺寸检查

```
检查项:
├── 所有坐标是否在打印体积内（0-270, 0-270, 0-270）
├── Z 轴高度是否与模型高度一致
├── 首层 Z 高度是否正确（0.2mm 或 0.28mm）
└── 层高增量是否一致
```

#### 4.2 挤出检查

```
检查项:
├── E 值是否单调递增（绝对挤出模式）
├── E 增量是否在合理范围（0.02-0.06/mm）
├── 是否存在 E 值回退未回抽的情况
├── 总挤出量是否与模型体积匹配（误差 < 20%）
└── 首层 E 值是否略高于标准层
```

#### 4.3 温度检查

```
检查项:
├── Start G-code 是否包含 M104/M109 设置热端温度
├── Start G-code 是否包含 M140/M190 设置热床温度
├── 温度值是否在耗材合理范围内
├── End G-code 是否包含 M104 S0 / M140 S0
└── 是否存在打印中途异常温度变化
```

#### 4.4 速度检查

```
检查项:
├── 首层速度 ≤ 30mm/s
├── 外墙速度 ≤ 60mm/s
├── 填充速度 ≤ 120mm/s
├── 旅行速度 ≤ 300mm/s
├── F 值单位是否正确（mm/min）
└── 是否存在异常高速度（> 300mm/s）
```

#### 4.5 层高检查

```
检查项:
├── 首层层高是否正确
├── 层高增量是否一致
├── 层高是否在合理范围（0.08-0.32mm）
├── 总层数是否与模型高度/层高匹配
└── 是否存在 Z 轴异常跳跃（> 1mm）
```

#### 4.6 回抽检查

```
检查项:
├── 旅行移动前是否有回抽
├── 回抽长度是否合理（0.4-2.0mm）
├── 回抽后是否有恢复挤出
├── 长距离旅行（> 5mm）是否有回抽
└── 工具切换时是否有回抽
```

#### 4.7 完整性检查

```
检查项:
├── 是否包含 Start G-code（M82, G28, 温度设置）
├── 是否包含 End G-code（M104 S0, M140 S0, M84）
├── 层号是否连续（无跳层）
├── 是否存在空层（有层注释但无 G1 指令）
├── M82 绝对挤出模式是否在开头设置
└── 是否包含 G28 归零指令
```
