# VoxelFlow AI — 知识库

## 1. 模型解释

### 1.1 文件格式

| 格式 | 类型 | 说明 |
|------|------|------|
| STL（二进制） | 三角面片集合 | 最常见的 3D 打印模型格式，仅包含几何信息（顶点+法线），无颜色/材质。每个面片由 3 个顶点和 1 个法向量组成，共 50 字节 |
| STL（ASCII） | 文本面片集合 | 可读性差、体积大，生产环境不使用 |
| 3MF | 增量制造格式 | 微软主导的开放标准，包含几何+颜色+材质+多部件+打印配置，推荐格式 |

### 1.3 关键分析维度

- **Bounding Box**: 模型在 X/Y/Z 轴的包围盒尺寸，用于判断是否适配打印平台、确定打印方向
- **面片数**: 反映模型复杂度，面片数 > 100 万时需注意切片性能
- **体积**: 用于估算耗材用量（体积 × 耗材密度 = 质量）
- **悬垂分析**: 面与水平面的夹角，>45° 需要支撑，>30° 建议支撑
- **薄壁分析**: 壁厚 < 2×线宽的区域，需要特殊处理（减少挤出或降层高）
- **桥接分析**: 两端固定、中间悬空的区域，需要减速+冷却策略

## 2. 切片管线

完整的 FDM 切片管线分为 6 步：

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  1.定向   │ →  │  2.层切   │ →  │  3.轮廓   │ →  │  4.填充   │ →  │  5.支撑   │ →  │  6.G-code│
│ Orient    │    │ Slice    │    │ Perimeter│    │ Infill   │    │ Support  │    │ Export   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 2.1 定向（Orientation）

- 目标：最小化悬垂面积和支撑用量
- 策略：最大投影面积朝下、平坦面朝下、功能面朝上
- CLI 输出 `orientation_suggestion` 提供推荐旋转角度

### 2.2 层切（Slicing）

- 将模型按层高（通常 0.2mm）水平切割
- 每层生成一个封闭的 2D 截面轮廓
- 首层层高可适当增加（0.2→0.28mm）以增强附着力

### 2.3 轮廓（Perimeter）

- 沿截面轮廓生成外墙（外轮廓）和内墙（内轮廓）
- 外墙：1-4 圈，影响表面质量和尺寸精度
- 内墙：与外墙配合形成壳体
- 生成顺序：外墙 → 内墙（由外向内）

### 2.4 填充（Infill）

- 在壳体内部生成支撑结构
- 图案类型：Grid、Gyroid、Honeycomb、Lines、Rectilinear、Triangles
- 密度：0-100%，常用 10-20%（结构件 30-50%）
- Gyroid 在各方向强度均匀，推荐作为默认

### 2.5 支撑（Support）

- 为悬垂和桥接区域生成临时支撑结构
- 类型：Tree（树状）、Linear（线状）、Auto（自动选择）
- 接口层间隙 0.2mm，便于拆除

### 2.6 G-code 生成（Export）

- 将所有路径转换为 G-code 指令
- 包含 Start G-code、逐层指令、End G-code
- 插入温度、风扇、回抽等控制指令

## 3. G-code 规范

### 3.1 Klipper 兼容指令集

#### 运动指令

| 指令 | 格式 | 说明 |
|------|------|------|
| G0 | `G0 X__ Y__ Z__` | 快速定位移动（不挤出） |
| G1 | `G1 X__ Y__ Z__ E__ F__` | 直线插补移动（可挤出） |
| G28 | `G28` | 归零所有轴 |
| G28 X | `G28 X` | 仅归零 X 轴 |
| G28 Y | `G28 Y` | 仅归零 Y 轴 |
| G28 Z | `G28 Z` | 仅归零 Z 轴 |

#### 挤出控制

| 指令 | 格式 | 说明 |
|------|------|------|
| M82 | `M82` | 设置绝对挤出模式（必须使用） |
| E 值 | `G1 X__ Y__ E__` | 累计挤出量，绝对模式下递增 |

#### 温度控制

| 指令 | 格式 | 说明 |
|------|------|------|
| M104 | `M104 S200` | 设置热端目标温度（不等待） |

| M140 | `M140 S60` | 设置热床目标温度（不等待） |
| M190 | `M190 S60` | 设置热床目标温度并等待 |

#### 风扇控制（Snapmaker U1 三风扇系统）

| 指令 | 格式 | 说明 |
|------|------|------|
| M106 | `M106 S255` | 设置主风扇（模型冷却）速度（0-255） |

### 3.3 完整 G-code 实例：20×20×5mm 立方体（PLA）

**打印参数：**
- 层高：0.2mm（首层 0.2mm）
- 线宽：0.4mm
- 丝材直径：1.75mm → 截面积 = π × 0.875² = 2.405 mm²
- 挤出膨胀系数：1.05
- E/mm（标准层）= (0.2 × 0.4) / 2.405 × 1.05 ≈ 0.035
- E/mm（首层）= (0.2 × 0.44) / 2.405 × 1.05 ≈ 0.0385（首层加宽线宽至 0.44mm）
- 外墙速度：45 mm/s → F2700
- 内墙速度：70 mm/s → F4200
- 填充速度：100 mm/s → F6000
- 首层速度：25 mm/s → F1500
- 旅行速度：200 mm/s → F12000
- 回抽量：1.2mm（PLA），1.5mm（PETG），0.4mm（TPU），回抽速度：40 mm/s → F2400
- 热端温度：210°C，热床温度：60°C
- 外墙 1 圈，内墙 1 圈，填充 15% Grid

**几何分析：**
- 立方体尺寸：20×20×5mm
- 总层数 = 5 / 0.2 = 25 层（层 0 ~ 层 24）
- 每层截面：20×20mm 正方形
- 外墙周长 = 4 × 20 = 80mm
- 内墙周长 = 4 × (20 - 2×0.4) = 4 × 19.2 = 76.8mm（内缩一个线宽）
- 填充区域边长 = 20 - 2×0.4×2 = 18.4mm（减去外墙+内墙各一线宽）
- 填充路径（15% Grid）：约 18.4 × 0.15 × 2 ≈ 5.52mm/层（双向正交线）

**每层 E 值估算：**
- 外墙 E = 80 × 0.035 = 2.800
- 内墙 E = 76.8 × 0.035 = 2.688
- 填充 E ≈ 5.52 × 0.035 ≈ 0.193
- 每层总 E ≈ 5.681

- 旅行移动用 G0（无 E 值），打印移动用 G1（带 E 值）
- 风扇策略：首层关闭 → 2-3 层低速 → 4 层起全速（PLA）
- Z 高度 = (层号 + 1) × 层高（层 0 的 Z = 0.2mm，层 1 的 Z = 0.4mm）

### 3.4 层标记格式要求

- Klipper 层进度追踪
- SET_PRINT_STATS_INFO 层号同步
- 打印机触摸屏显示当前层数

格式：
```
;LAYER:0
G0 Z0.2 F300
; ... 首层内容 ...

;LAYER:1
G0 Z0.4 F300
; ... 第2层内容 ...
```

注意：`;LAYER:N` 必须在 Z 轴移动之前，且 N 必须从 0 开始递增。

## 4. 挤出计算

### 4.1 核心公式

挤出量 E 值的计算基于体积守恒原理：**挤出的丝材体积 = 沉积的线材体积**

```
E/mm = (层高 × 线宽) / 丝材截面积
```

### 4.2 详细推导

```
丝材截面积 = π × (丝材直径/2)²
           = π × (1.75/2)²
           = π × 0.875²
           = 2.405 mm²

标准条件（0.2mm 层高, 0.4mm 线宽）:
E/mm = (0.2 × 0.4) / 2.405
     = 0.08 / 2.405
     ≈ 0.0333

考虑挤出膨胀系数（1.05）:
E/mm = 0.0333 × 1.05
     ≈ 0.035
```

### 4.3 不同条件下的 E/mm

| 层高 (mm) | 线宽 (mm) | E/mm | 说明 |
|-----------|-----------|------|------|
| 0.12 | 0.4 | 0.0209 | 精细打印 |
| 0.16 | 0.4 | 0.0279 | 高质量 |
| 0.20 | 0.4 | 0.0333 | 标准质量 |
| 0.20 | 0.4 | 0.0350 | 标准质量（含膨胀系数） |
| 0.24 | 0.4 | 0.0399 | 快速打印 |
| 0.28 | 0.4 | 0.0466 | 首层（增强附着） |
| 0.20 | 0.44 | 0.0367 | 首层（加宽线宽） |

### 4.4 首层特殊计算

首层需要更高的挤出量以确保附着力：

```
首层层高 = 0.28mm（标准层高 × 1.4）
首层线宽 = 0.44mm（标准线宽 × 1.1）

E/mm_首层 = (0.28 × 0.44) / 2.405 × 1.05
          = 0.1232 / 2.405 × 1.05
          ≈ 0.0538

简化值: E/mm_首层 ≈ 0.0367（使用 0.2mm 层高 + 0.44mm 线宽）
```

### 4.5 累计 E 值计算

绝对挤出模式下，E 值为累计值：

```
E_current = E_previous + (segment_length × E/mm)
```

示例：
```
; 起点 E=0
G1 X10 Y0 E0.350     ; 移动 10mm, E = 0 + 10 × 0.035 = 0.350
G1 X10 Y10 E0.700    ; 移动 10mm, E = 0.350 + 10 × 0.035 = 0.700
G1 X0 Y10 E1.050     ; 移动 10mm, E = 0.700 + 10 × 0.035 = 1.050
G1 X0 Y0 E1.400      ; 移动 10mm, E = 1.050 + 10 × 0.035 = 1.400
```

### 4.6 逐段计算详解：矩形周长

以一个 30×20mm 矩形外墙为例，起点 (10, 10)，标准层 E/mm = 0.035：

```
矩形顶点: A(10,10) → B(40,10) → C(40,30) → D(10,30) → A(10,10)

段 AB: (10,10) → (40,10)
  长度 = √((40-10)² + (10-10)²) = √(900 + 0) = 30.000mm
  E增量 = 30.000 × 0.035 = 1.050
  E累计 = 0 + 1.050 = 1.050
  G1 X40 Y10 E1.050 F2700

段 BC: (40,10) → (40,30)
  长度 = √((40-40)² + (30-10)²) = √(0 + 400) = 20.000mm
  E增量 = 20.000 × 0.035 = 0.700
  E累计 = 1.050 + 0.700 = 1.750
  G1 X40 Y30 E1.750 F2700

段 CD: (40,30) → (10,30)
  长度 = √((10-40)² + (30-30)²) = √(900 + 0) = 30.000mm
  E增量 = 30.000 × 0.035 = 1.050
  E累计 = 1.750 + 1.050 = 2.800
  G1 X10 Y30 E2.800 F2700

段 DA: (10,30) → (10,10)
  长度 = √((10-10)² + (10-30)²) = √(0 + 400) = 20.000mm
  E增量 = 20.000 × 0.035 = 0.700
  E累计 = 2.800 + 0.700 = 3.500
  G1 X10 Y10 E3.500 F2700

验证: 周长 = 2×(30+20) = 100mm, 总E = 100 × 0.035 = 3.500 ✓
```

### 4.7 挤出计算检查清单

生成每一段 G1 指令时，必须按此清单逐项确认：

```
□ 1. 确认当前 E/mm 值（首层/标准层/桥接段各不同）
□ 2. 计算段长度 = √((x2-x1)² + (y2-y1)²)
□ 3. 计算 E增量 = 段长度 × E/mm
□ 4. 计算 E累计 = E_previous + E增量
□ 5. 确认 E累计 > E_previous（绝对模式下必须递增）
□ 6. 确认段长度 > 0（零长度段不应生成 G1）
□ 7. 确认 F 值正确（外墙/内墙/填充/首层 速度不同）
□ 8. 确认坐标在打印范围内（0-270mm for X/Y, 0-270mm for Z）
```

## 10. 空间推理框架

本节是 LLM 将 RawPath 坐标数据转化为 G-code 的核心认知框架。必须严格按照本节方法理解和处理空间数据。

### 10.1 RawPath 坐标的空间含义

RawPath 中的 `points` 数组是一组 **[x, y] 二维坐标**，代表在某个 Z 高度上的 2D 截面轮廓。

```
理解模型：
  3D 模型 = 一系列 Z 高度上的 2D 截面叠加
  每层 RawPath = 一个 Z 高度上的 2D 截面描述

  Z=0.2mm:  ████████████  ← layer 0 的 2D 截面
  Z=0.4mm:  ████████████  ← layer 1 的 2D 截面
  Z=0.6mm:  ████████████  ← layer 2 的 2D 截面
  ...
  Z=5.0mm:  ████████████  ← layer 24 的 2D 截面

  每个截面包含：
  - perimeters: 壁体轮廓（外墙 + 内墙）
  - infill: 内部填充路径
  - support: 支撑路径（如需要）
```

**关键认知：** points 数组中的 [x, y] 是打印平台上的绝对坐标，单位为毫米。Z 坐标由 `z_height` 字段提供，不需要从 points 中提取。

### 10.2 从点序列到 G1 指令的转换

RawPath 中一个路径的 `points` 数组，例如：

```json
"points": [[10, 10], [30, 10], [30, 30], [10, 30], [10, 10]]
```

转换规则：
- 第一个点 `[10, 10]` 是路径起点 → 生成 G0 旅行移动到该点
- 后续每个点 → 生成 G1 打印移动到该点（带 E 值）
- 最后一个点与第一个点相同时 → 路径闭合（封闭轮廓）

```
转换结果：
G0 X10 Y10 F12000           ; 旅行到起点 [10,10]
G1 X30 Y10 E{E1} F2700      ; 打印到 [30,10]
G1 X30 Y30 E{E2} F2700      ; 打印到 [30,30]
G1 X10 Y30 E{E3} F2700      ; 打印到 [10,30]
G1 X10 Y10 E{E4} F2700      ; 打印回起点 [10,10]，闭合轮廓
```

### 10.3 段长度计算

每两个相邻点之间构成一个"段"（segment），段长度是计算 E 值的基础。

**公式：**
```
segment_length = √((x2 - x1)² + (y2 - y1)²)
```

**各类情况：**

```
1. 纯水平移动（y 不变）:
   点 (10, 20) → (30, 20)
   长度 = √((30-10)² + (20-20)²) = √(400 + 0) = 20.000mm

2. 纯垂直移动（x 不变）:
   点 (15, 10) → (15, 35)
   长度 = √((15-15)² + (35-10)²) = √(0 + 625) = 25.000mm

3. 对角线移动:
   点 (10, 10) → (20, 25)
   长度 = √((20-10)² + (25-10)²) = √(100 + 225) = √325 ≈ 18.028mm

4. 闭合矩形验证:
   (0,0)→(20,0)→(20,20)→(0,20)→(0,0)
   段1: 20mm, 段2: 20mm, 段3: 20mm, 段4: 20mm
   总长: 80mm = 4 × 20 ✓
```

### 10.4 旅行移动 vs 打印移动的判定

**核心规则：**

| 情况 | 移动类型 | G-code 指令 | 是否有 E 值 |
|------|---------|------------|------------|
| 同一路径内相邻点 | 打印移动 | G1 X__ Y__ E__ F__ | 有（挤出） |
| 切换到新路径 | 旅行移动 | G0 X__ Y__ F__ | 无（不挤出） |
| 换层（Z 高度变化） | 旅行移动 | G0 Z__ F__ | 无 |
| 回抽后移动 | 旅行移动 | G0 X__ Y__ F__ | 无 |

**判定流程：**

```
对于 RawPath 中的每个路径（perimeter/infill/support）:
  1. 路径的第一个点 → G0 旅行移动到该点（可能需要回抽）
  2. 路径内后续点 → G1 打印移动（带 E 值）
  3. 路径结束后 → 准备回抽，然后 G0 旅行到下一路径起点

特殊情况：
  - 如果两个路径起点距离 < 1mm，可以不回抽直接移动
  - 如果旅行距离 > 5mm，必须回抽
  - 外墙路径之间通常需要回抽
  - 填充路径之间如果连续可不断挤
```

### 10.5 Z 高度与层号的映射

```
层号 (layer_index) 从 0 开始

Z 高度计算:
  Z = (layer_index + 1) × layer_height

示例（layer_height = 0.2mm）:
  layer 0 → Z = (0+1) × 0.2 = 0.2mm    ← 首层
  layer 1 → Z = (1+1) × 0.2 = 0.4mm
  layer 2 → Z = (2+1) × 0.2 = 0.6mm
  ...
  layer 24 → Z = (24+1) × 0.2 = 5.0mm

反向映射（从 Z 高度推算层号）:
  layer_n = floor(z / layer_height) - 1
  或更准确: layer_n = round(z / layer_height) - 1

注意: RawPath 中 z_height 字段已直接提供 Z 值，无需自行计算。
但验证时可用此公式检查 z_height 是否正确。
```

### 10.6 坐标系方向与路径方向

```
坐标系定义（右手法则）:
  原点 (0,0) 在左前下角
  X 轴: 左→右（0→270mm）
  Y 轴: 前→后（0→270mm）
  Z 轴: 下→上（0→270mm）

路径方向对打印的影响:
  - 外墙通常逆时针（CCW）绘制 → 保证挤出方向使材料堆叠在轮廓内侧
  - 内墙通常顺时针（CW）绘制 → 保证材料堆叠在轮廓外侧
  - 填充方向无特定要求，但相邻层通常旋转 45°/90° 以增强强度
```

### 10.7 判定路径顺逆时针

给定一组闭合点序列，使用**有向面积法**判定方向：

```
有向面积 S = 0.5 × Σ[(x_i × y_{i+1}) - (x_{i+1} × y_i)]

如果 S > 0 → 逆时针（CCW）
如果 S < 0 → 顺时针（CW）
如果 S = 0 → 退化路径（共线点）

示例: 矩形 (0,0) → (20,0) → (20,20) → (0,20) → (0,0)

S = 0.5 × [(0×0 - 20×0) + (20×20 - 20×0) + (20×20 - 0×20) + (0×0 - 0×20)]
  = 0.5 × [0 + 400 + 400 + 0]
  = 400

S > 0 → 逆时针（CCW）→ 这是外墙方向 ✓
```

**方向与墙类型对应关系：**

| 路径方向 | 墙类型 | 说明 |
|---------|--------|------|
| 逆时针（CCW） | 外墙 | 材料堆叠在轮廓内侧，表面质量好 |
| 顺时针（CW） | 内墙 | 材料堆叠在轮廓外侧，与外墙形成壳体 |

## 11. 逐步计算方法论

本节定义从 RawPath 到完整 G-code 的严格、可重复的计算流程。**每一步必须按顺序执行，不可跳过。**

### 11.1 完整流程

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 解析 RawPath                                         │
│   - 提取所有层（layers）                                      │
│   - 每层提取: perimeters, infill, support                    │
│   - 记录每层的 z_height                                      │
├─────────────────────────────────────────────────────────────┤
│ Step 2: 计算每层 Z 高度                                       │
│   - Z = z_height（直接使用 RawPath 提供的值）                  │
│   - 验证: Z = (layer_index + 1) × layer_height              │
│   - 首层特殊标记: layer_index === 0                           │
├─────────────────────────────────────────────────────────────┤
│ Step 3: 逐段计算挤出量                                        │
│   对每层中的每个路径（perimeter → infill → support 顺序）:      │
│     对路径中每对相邻点 (x1,y1) → (x2,y2):                     │
│       a. segment_length = √((x2-x1)² + (y2-y1)²)           │
│       b. 确定当前 E/mm（基于路径类型和是否首层）                 │
│       c. E_increment = segment_length × E/mm                 │
│       d. E_current = E_previous + E_increment                │
├─────────────────────────────────────────────────────────────┤
│ Step 4: 生成 G1 指令                                         │
│   G1 X{x2} Y{y2} E{E_current} F{speed}                     │
│   - speed 根据路径类型选择:                                    │
│     外墙 → F2700, 内墙 → F4200, 填充 → F6000, 首层 → F1500  │
├─────────────────────────────────────────────────────────────┤
│ Step 5: 生成旅行移动                                          │
│   路径起点: G0 X{x} Y{y} F12000                             │
│   换层:     G0 Z{z} F300                                     │
│   首层起点前: G0 Z5 F3000 → G0 X{x} Y{y} F12000 → G0 Z{z} F300 │
├─────────────────────────────────────────────────────────────┤
│ Step 6: 插入回抽指令                                          │
│   在旅行移动前插入:                                           │
│     G1 E{E_current - retraction_amount} F2400               │
│   在旅行移动后、打印前插入:                                    │
│     G1 E{E_current} F2400                                    │
│   回抽量: 1.2mm（PLA）, 1.5mm（PETG）, 0.4mm（TPU）          │
├─────────────────────────────────────────────────────────────┤
│ Step 7: 插入层边界控制指令                                     │
│   首层 (layer 0):                                            │
│     M106 S0                    ; 风扇关闭                     │
│   第2-3层 (layer 1-2):                                        │
│     M106 S85                   ; 风扇低速                     │
│   第4层起 (layer 3+):                                         │
│     M106 S255                  ; 风扇全速（PLA）              │
│   桥接/悬垂段:                                                │
│     M106 S255                  ; 临时全速                     │
├─────────────────────────────────────────────────────────────┤
│ Step 8: 添加 Start/End G-code                                │
│   Start: M82, 温度, G28, 等待, 安全高度移动                    │
│   End: M400, M106 S0, M104 S0, M140 S0, 安全移动, M84       │
└─────────────────────────────────────────────────────────────┘
```

### 11.2 伪代码实现

```
function generate_gcode(raw_paths, config):
    E = 0                          // 累计挤出量
    output = []                    // G-code 行列表

    // === Start G-code ===
    output.append("M82")
    output.append(f"M140 S{config.bed_temp}")
    output.append(f"M104 S{config.hotend_temp}")
    output.append("G28")
    output.append(f"M190 S{config.bed_temp}")
    output.append(f"M109 S{config.hotend_temp}")
    output.append("G0 Z5 F3000")

    for layer in raw_paths:
        layer_index = layer.layer
        z = layer.z_height
        is_first_layer = (layer_index == 0)

        // 层边界控制
        if is_first_layer:
            output.append("M106 S0")           // 首层风扇关闭
        elif layer_index <= 2:
            output.append("M106 S85")          // 低速风扇
        else:
            output.append("M106 S255")         // 全速风扇（PLA）

        // 换层移动
        output.append(f"G0 Z{z:.2f} F300")

        // 确定本层 E/mm
        if is_first_layer:
            e_per_mm = config.e_per_mm_first   // 首层 E/mm
            speed = config.first_layer_speed
        else:
            e_per_mm = config.e_per_mm         // 标准层 E/mm

        // 处理 perimeters
        for perimeter in layer.perimeters:
            // 旅行到起点
            start = perimeter.points[0]
            output.append(f"G0 X{start[0]:.2f} Y{start[1]:.2f} F12000")

            // 确定速度
            if perimeter.type == "external":
                speed = config.perimeter_speed  // F2700
            else:
                speed = config.inner_wall_speed // F4200

            // 逐段生成 G1
            for i in range(1, len(perimeter.points)):
                p1 = perimeter.points[i-1]
                p2 = perimeter.points[i]
                seg_len = sqrt((p2[0]-p1[0])**2 + (p2[1]-p1[1])**2)
                E = E + seg_len * e_per_mm
                output.append(f"G1 X{p2[0]:.2f} Y{p2[1]:.2f} E{E:.3f} F{speed}")

        // 处理 infill
        for infill_path in layer.infill:
            start = infill_path.points[0]
            output.append(f"G0 X{start[0]:.2f} Y{start[1]:.2f} F12000")

            for i in range(1, len(infill_path.points)):
                p1 = infill_path.points[i-1]
                p2 = infill_path.points[i]
                seg_len = sqrt((p2[0]-p1[0])**2 + (p2[1]-p1[1])**2)
                E = E + seg_len * e_per_mm
                output.append(f"G1 X{p2[0]:.2f} Y{p2[1]:.2f} E{E:.3f} F{config.infill_speed}")

        // 处理 support（如存在）
        for support_path in layer.support:
            start = support_path.points[0]
            output.append(f"G0 X{start[0]:.2f} Y{start[1]:.2f} F12000")

            for i in range(1, len(support_path.points)):
                p1 = support_path.points[i-1]
                p2 = support_path.points[i]
                seg_len = sqrt((p2[0]-p1[0])**2 + (p2[1]-p1[1])**2)
                E = E + seg_len * e_per_mm
                output.append(f"G1 X{p2[0]:.2f} Y{p2[1]:.2f} E{E:.3f} F{config.support_speed}")

    // === End G-code ===
    output.append("M400")
    output.append("M106 S0")
    output.append("M104 S0")
    output.append("M140 S0")
    output.append("G0 X0 Y270 F5000")
    output.append("G0 Z15 F300")
    output.append("M84")

    return output
```

### 11.3 E 值精度要求

```
E 值保留小数位数: 3 位（如 E12.345）
坐标保留小数位数: 2 位（如 X10.44）
F 值为整数（如 F2700）

计算中间值保留: 至少 6 位小数，仅在输出时截断
示例:
  seg_len = 19.123456mm
  E_increment = 19.123456 × 0.035 = 0.669321mm
  E_current = 12.980000 + 0.669321 = 13.649321mm
  输出: G1 X29.56 Y10.44 E13.649 F2700
```

## 12. 自验证检查清单

生成 G-code 后，**必须**逐项检查以下规则。任何一项不通过，都必须修正后重新输出。

### 12.1 E 值验证

| # | 检查项 | 规则 | 错误示例 | 正确示例 |
|---|--------|------|---------|---------|
| 1 | E 值单调递增 | 绝对模式下，每条 G1 的 E 值必须 > 前一条 G1 的 E 值 | E2.500 → E2.300 | E2.500 → E2.800 |
| 2 | E 增量合理 | E增量 = 段长度 × E/mm，误差 < 5% | 20mm段 E增量=1.400（E/mm=0.035时应=0.700） | 20mm段 E增量=0.700 |
| 3 | 总 E 值估算 | 总E ≈ 总路径长度 × E/mm，偏差 < 10% | 总路径1000mm，总E=10（应为~35） | 总路径1000mm，总E=35 |
| 4 | 无原地挤出 | G1 带 E 值时，X 或 Y 必须有变化 | G1 X10.00 Y10.00 E5.000 | G1 X30.00 Y10.00 E5.700 |

### 12.2 坐标验证

| # | 检查项 | 规则 | 错误示例 | 正确示例 |
|---|--------|------|---------|---------|
| 5 | X 范围 | 0 ≤ X ≤ 270 | X275.00 | X270.00 |
| 6 | Y 范围 | 0 ≤ Y ≤ 270 | Y-5.00 | Y0.00 |
| 7 | Z 范围 | 0 < Z ≤ 270 | Z275.00 | Z270.00 |
| 8 | Z 递增 | 层间 Z 值必须递增 | Z0.6 → Z0.4 | Z0.4 → Z0.6 |
| 9 | 段长度合理 | 0 < 段长度 < 500mm | 长度=0 或 长度=800 | 长度=20.000 |

### 12.3 结构验证

| # | 检查项 | 规则 |
|---|--------|------|
| 10 | Start G-code 包含 M82 | 必须在文件开头设置绝对挤出模式 |
| 11 | Start G-code 包含温度指令 | M104/M109 + M140/M190 必须存在 |
| 12 | Start G-code 包含 G28 | 必须归零 |
| 13 | 首层风扇关闭 | 首层必须有 M106 S0 |
| 14 | End G-code 包含 M104 S0 | 关闭热端 |
| 15 | End G-code 包含 M140 S0 | 关闭热床 |
| 16 | End G-code 包含 M84 | 关闭电机 |
| 17 | 每层有 Z 移动 | 每层开始必须有 G0 Z__ |
| 18 | 层注释存在 | 每层应有 ;LAYER:N 注释 |

### 12.4 快速验证脚本（心理模拟）

生成 G-code 后，按以下步骤快速验证：

```
1. 扫描所有 E 值，确认单调递增
   → 如果发现 E 值减小或不变（非回抽行），立即修正

2. 检查首行: 必须包含 M82
   → 如果没有，添加

3. 检查首层: 必须包含 M106 S0
   → 如果没有，添加

4. 检查末行: 必须包含 M104 S0, M140 S0, M84
   → 如果缺少，添加

5. 抽查 3 段 G1 的 E 增量:
   → 计算段长度 = √((X2-X1)² + (Y2-Y1)²)
   → 计算 E增量 = E2 - E1
   → 验证 E增量 / 段长度 ≈ E/mm（误差 < 10%）

6. 检查最大坐标:
   → 所有 X ≤ 270, Y ≤ 270, Z ≤ 270

7. 检查 Z 值序列:
   → 每层 Z 值递增，增量 ≈ layer_height
```

### 12.5 常见错误模式

| 错误模式 | 现象 | 根因 | 修正 |
|---------|------|------|------|
| E 值回退 | E 从 5.0 降到 4.8 | 误用相对模式逻辑 | 确认 M82，E 始终累加 |
| 原地挤出 | G1 X10 Y10 E5.0 | 漏算坐标变化 | 检查相邻点是否相同 |
| Z 不变 | 连续两层 Z=0.4 | 漏算层高 | Z = (n+1) × layer_height |
| 首层风扇全速 | M106 S255 在 layer 0 | 风扇策略错误 | 首层 M106 S0 |
| 缺少回抽 | 长距离旅行无回抽 | 漏插回抽指令 | 旅行 > 5mm 必须回抽 |
| 坐标超限 | X=360 | 模型超出打印范围 | 检查模型尺寸或居中偏移 |
| F 值错误 | 外墙 F6000 | 速度策略混淆 | 外墙 F2700，填充 F6000 |
